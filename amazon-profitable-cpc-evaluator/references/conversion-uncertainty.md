# Conversion Uncertainty

Use this guide when conversion data is available but not perfectly stable.

## Why this matters

Observed conversion rate is not fixed.
It changes with:
- seasonality
- traffic quality
- review count
- price changes
- stock state
- market pressure
- ad position

## Default interpretation

When possible, build three scenarios:
- low conversion = prudent case
- median conversion = normal case
- high conversion = optimistic case

Then calculate:
- prudent CPC
- median CPC
- aggressive CPC

## Data quality warning

If sample size is small, say that clearly.
A conversion rate based on weak volume should not be treated as stable.

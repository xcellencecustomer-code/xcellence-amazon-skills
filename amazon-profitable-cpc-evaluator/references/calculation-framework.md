# Calculation Framework

Use this framework for profitable CPC evaluation.

## Core formula

### Profitable CPC
profitable cpc = selling price × conversion rate × tacos target

This gives the supportable CPC under the selected assumptions.

## Interpretation rule

This number is a ceiling, not an automatic bid recommendation.

If the user wants safer execution, recommend staying under the prudent or median case rather than leaning on the upper case.

## Practical reading

- higher price increases supportable CPC
- higher conversion increases supportable CPC
- higher acceptable TACOS increases supportable CPC

The product only supports a strong CPC if all three align.

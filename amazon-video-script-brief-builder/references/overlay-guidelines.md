# Overlay Guidelines

Use this guide for on-screen text in Amazon videos.

## Overlay rules

- Keep text short
- Prioritize benefits over jargon
- Write for fast reading on mobile
- Let the image do most of the work
- Avoid paragraph-like overlays

## Good overlay patterns

- stronger protection
- easy to clean
- fits in seconds
- no plastic noise
- more comfortable grip
- compact for travel

## Avoid

- vague superiority language
- long explanatory sentences
- duplicated text across scenes
- lines that restate what is already obvious

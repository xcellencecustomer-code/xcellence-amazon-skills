# Rewrite Checklist

Use this when improving existing Amazon bullets.

## Diagnose the current bullets

Check for:
- weak first bullet
- repeated promises
- vague language
- poor scanability
- technical overload
- missing buyer benefit
- missing objection handling
- weak or absent reassurance

## Removal priorities

Remove or rewrite first:
- empty claims
- duplicated ideas
- broad adjectives
- unsupported superiority claims
- feature lists with no customer meaning

## Compare old vs new

After rewriting, explain:
- what was weak before
- what changed
- why each new bullet has a clearer job
- why the set is more persuasive

## Variant strategy

When useful, create variants such as:
- stronger conversion version
- cleaner and more premium-feeling version
- more category-specific version

Then recommend the strongest one for the user’s goal.

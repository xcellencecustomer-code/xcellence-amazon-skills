# Bullet Framework

Use this framework to structure Amazon bullets as a persuasion path.

## Core principle

A strong bullet set is not a list of product facts. It is a short conversion sequence.

## Default 5-bullet order

### Bullet 1 — Main buying promise
Lead with the most commercially important value for the target buyer.

### Bullet 2 — Reinforcing value
Add the second strongest reason to want the product.

### Bullet 3 — Useful concrete support
Bring in technical or practical detail that helps the buyer evaluate the product.

### Bullet 4 — Differentiation
Answer the question: why choose this one instead of another?

### Bullet 5 — Reassurance
Lower the purchase risk with trust, confidence, brand seriousness, or reduced-friction messaging.

## Bullet mission rule

Each bullet should have one dominant mission:
- desire
- support
- proof
- preference
- reassurance

If one bullet tries to do everything, split or simplify.

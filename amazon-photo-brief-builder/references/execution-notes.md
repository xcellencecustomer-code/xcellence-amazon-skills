# Execution Notes

Use this guide to turn strategy into a usable creative brief.

## For each image, specify:
- objective
- message
- one-second takeaway
- image type
- composition idea
- specific detail to show
- objection or benefit supported
- text overlay guidance, if any
- mobile readability warning, if relevant

## Execution principle

Do not brief visuals in vague terms such as:
- make it premium
- make it modern
- make it elegant

Instead brief in sales terms:
- show the liquid staying on the surface
- show the fit on the mattress corners
- show the material texture up close
- show before/after volume reduction
- show the exact pack contents

## Text overlay rule

If a secondary image uses text:
- keep it short
- keep it scannable
- make the visual carry most of the message
- never rely on paragraph-length explanation

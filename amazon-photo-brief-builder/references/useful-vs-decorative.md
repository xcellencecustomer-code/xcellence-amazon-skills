# Useful vs Decorative Images

Use this guide to judge whether an image deserves a place in the listing.

## Useful image

A useful image does one or more of these:
- makes a core benefit obvious
- proves a product claim
- answers a buyer question
- reduces hesitation
- shows usage clearly
- clarifies fit, size, or contents
- helps the buyer compare or choose

## Decorative image

A decorative image usually:
- repeats information already shown
- looks attractive but adds no commercial value
- prioritizes atmosphere over clarity
- hides the product
- depends on too much text
- would not be missed if removed

## Fast test

Ask:
1. What new selling value does this image add?
2. Which doubt does it remove?
3. Which key message does it make clearer?
4. Would the listing lose selling power if this image disappeared?

If the answer to question 4 is no, the image is probably decorative.

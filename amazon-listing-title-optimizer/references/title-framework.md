# Title Framework

Use this framework to build Amazon titles in a disciplined order.

## Core principle

A title should not be an accumulation of words. It should be an ordered stack of information.

## Default order

1. Brand
2. Product type
3. Main qualifier or major buying attribute
4. Critical size, capacity, quantity, compatibility, or model detail
5. One or two differentiators
6. Optional usage context only if it improves filtering

## Typical element types

### Product identity
- what the product is
- the most standard and buyer-recognizable product term

### Buying attribute
- the strongest feature or qualifier affecting the purchase decision

### Commercial filter
- size
- capacity
- quantity
- compatibility
- dimension
- format

### Differentiator
- one or two useful benefits that reduce a real objection

## Practical rule

Every block in the title should do one of these jobs:
- identify
- qualify
- filter
- differentiate

If a word does none of these, remove it.

# Rewrite Checklist

Use this when improving an existing title.

## Diagnose the original title

Check for:
- poor ordering
- repeated words or ideas
- vague claims
- filler adjectives
- excessive density
- awkward readability
- weak size or compatibility formatting
- unnecessary color or variant details

## Removal priorities

Remove first:
- vague promotional language
- duplicated product terms
- weak adjectives
- low-value extras
- unnecessary filler

## Compare old vs new

After rewriting, explain:
- what was removed
- what stayed
- what moved earlier
- why the new title is more readable
- why the new title is more commercially useful

## Variant strategy

When useful, produce:
- one more SEO-leaning version
- one more readable version
- one more conversion-leaning version

Then recommend the strongest balance.

# True Strengths, Weaknesses, and False Advantages

Use this file to classify product signals correctly.

## True strength

A true strength usually meets all of these conditions:
- buyers care about it
- buyers can perceive it
- it is credible
- it changes purchase likelihood or product satisfaction

Examples:
- clearer problem solution
- easier use
- better fit for a valued segment
- stronger durability with believable proof
- more complete offer when completeness matters

## Weakness

A weakness is anything that:
- creates hesitation
- lowers desirability
- weakens perceived value
- makes the offer easier to reject
- exposes the product to stronger competition

Examples:
- vague promise
- price not justified
- weak proof
- too-generic positioning
- recurring review complaint
- poor fit with the strongest buyer need

## False advantage

A false advantage is something presented as differentiating but that does not create real buyer preference.

Common types:
1. Invisible advantage
2. Unimportant advantage
3. Non-exclusive advantage
4. Non-credible advantage

Test every supposed advantage with these questions:
- does the buyer care?
- does the buyer understand it quickly?
- does it change choice?
- can competitors say the same thing?
- can it be proved?

# Target Zone Logic

Use this guide to set realistic conversion expectations.

## Do not use one magic target

A realistic target depends on:
- product simplicity or complexity
- ticket size
- buyer intent
- market competition
- current listing maturity
- proof layer such as review count and quality

## Use three target levels

### Minimum acceptable
Below this, the product becomes economically or strategically weak.

### Healthy zone
The product is functioning properly for its context.

### Realistic excellence
The upper range that may be achievable if traffic, offer, and listing are strongly optimized.

## Action rule

A target is useful only if it informs the next decision:
- improve traffic
- improve listing
- improve offer
- improve product
- wait for more reliable data

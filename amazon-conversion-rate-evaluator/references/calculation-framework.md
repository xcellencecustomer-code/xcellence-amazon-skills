# Calculation Framework

Use this framework for Amazon conversion-rate evaluation.

## Two useful interpretations

### Classic conversion rate
orders / visitors or sessions

Use this when the user wants a standard, broad conversion reading.

### Buying-opportunity conversion
Use when Buy Box or equivalent buying-opportunity data matters.

The point is not to pretend there is only one formula.
The point is to be explicit about what the ratio measures.

## Interpretation rule

The observed rate must always be read together with:
- traffic quality
- volume reliability
- offer conditions
- listing strength
- product context

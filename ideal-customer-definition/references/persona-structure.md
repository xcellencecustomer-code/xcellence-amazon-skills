# Persona Structure

Use this when building the final ideal-customer persona.

## Goal

Create a persona that is useful for:
- positioning
- copywriting
- ads
- listings
- landing pages
- objection handling

Do not create a decorative lifestyle profile unless it helps buying logic.

## Default persona structure

### 1. Profile summary
### 2. Life context
### 3. Main problems
### 4. Daily frustrations
### 5. Fears and emotional tensions
### 6. Desired outcomes
### 7. Buying criteria
### 8. Objections
### 9. What they need to hear
### 10. Action triggers

## Evidence discipline

If a detail is grounded in the product logic, present it firmly.
If a detail is inferred but not certain, label it as probable.
If it is only possible, do not present it as a fact.

## Summary sentence format

End with a one-sentence version of the persona in this spirit:

"[type of buyer] who wants [core result] without [main fear or tradeoff], and is motivated by [main practical or emotional driver]."

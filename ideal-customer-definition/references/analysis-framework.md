# Analysis Framework

Use this framework to move from a product to an ideal customer profile.

## Core logic

Always reason in this order:

1. What does the product actually do?
2. Which features have real customer impact?
3. What concrete benefit comes from each important feature?
4. What customer problem does that benefit help solve?
5. For whom does that problem matter the most?
6. Which segment has the clearest fit?
7. What persona and messaging follow from that fit?

## Feature analysis template

Use this pattern for each meaningful feature:

### Feature
[feature name]

### Concrete benefit
[what it practically improves]

### Customer problem solved
[what pain, inconvenience, fear, or friction it reduces]

### Customer type most affected
[who cares most and why]

### Notes
[optional: which objection this helps reduce, or why this feature matters commercially]

## Segment ranking logic

Rank segments according to:
- clarity of problem
- urgency or frequency of need
- speed of value recognition
- fit between product strengths and customer context
- risk of mismatch or disappointment
- ease of explaining the value proposition
- strength of likely messaging angles

## Strategic rule

The best segment is not the largest imaginable audience. It is the segment where:
- the problem is most real
- the value is easiest to understand
- the fit is strongest
- the post-purchase satisfaction is likely to be highest
